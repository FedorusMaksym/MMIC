## 📖 Про проєкт

Сайт допомагає користувачам знайти та забронювати серф-кемп, дізнатися про локації та інструкторів, а також приєднатися до спільноти серфінгістів.

**Основні можливості:**

- 🌊 Каталог серф-кемпів і напрямків
- 📅 Бронювання подорожей
- 👥 Розділ спільноти
- 📱 Адаптивна верстка (desktop / tablet / mobile)
- ✨ Акуратна типографіка та візуальний стиль за макетом

> Відредагуй цей список відповідно до реальних секцій твого макета.
