## 📖 Про проєкт

Сайт допомагає користувачам знайти та забронювати серф-кемп, дізнатися про локації та інструкторів, а також приєднатися до спільноти серфінгістів.

**Основні можливості:**

- 🌊 Каталог серф-кемпів і напрямків
- 📅 Бронювання подорожей
- 👥 Розділ спільноти
- 📱 Адаптивна верстка (desktop / tablet / mobile)
- ✨ Акуратна типографіка та візуальний стиль за макетом

> Відредагуй цей список відповідно до реальних секцій твого макета.

## 🚀 Початок роботи

### Вимоги

- [Node.js](https://nodejs.org/) `>= 18`
- npm або yarn

### Встановлення

```bash
# клонувати репозиторій
git clone https://github.com/<your-username>/<your-repo>.git

# перейти в папку проєкту
cd <your-repo>

# встановити залежності
npm install
```

### Запуск

```bash
# режим розробки
npm run dev

# збірка для продакшну
npm run build
```

Після запуску відкрий [http://localhost:3000](http://localhost:3000) у браузері.
